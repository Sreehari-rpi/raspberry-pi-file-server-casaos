# 📁 Raspberry Pi File Server using CasaOS

## 📌 Overview
This project is a self-hosted file server built using a Raspberry Pi and CasaOS. It allows easy file storage, sharing, and management over a local network through a simple web interface.

---

## ⚙️ Hardware Used
- Raspberry Pi (any model like Pi 3 / Pi 4)
- MicroSD Card (16GB or more recommended)
- Power supply
- Network connection (WiFi or Ethernet)
- External HDD/SSD (optional for extra storage)

---

## 💻 Software Used
- CasaOS
- Raspberry Pi OS (Lite or Desktop)
- Web browser for access

---

## 🚀 Features
- Easy file upload and download
- Web-based dashboard
- Access files from mobile or PC
- Local network file sharing
- Simple setup with CasaOS

---

## 🛠️ Setup Steps
1. Install Raspberry Pi OS on SD card
2. Boot Raspberry Pi and connect to internet
3. Install CasaOS using official script:

   curl -fsSL https://get.casaos.io | bash
